1. Перейти на главную UI (страница «Lots»).
2. Нажать «+ Новый лот» (в форме):
   ```
   Сырая заявка:
   Срочно нужно металла на стройку. Швеллер 14-й, тонн 10. Арматура А500 диаметром 12, тонн 5. Листы 3мм 09Г2С, тонн 8.
   Контакт: Сидоров +79161234567

   ```
3. Нажать «Создать». Лот появится в списке со статусом `draft → planned → sourcing → ...`.

**Спикер во время автозапуска (≈30 сек):**

4. Открыть лот → видим:
   - Top-3 поставщика с ценой, ИНН, сроком, score

## Q&A — Готовые ответы

| Вопрос | Ответ |
|---|---|
| Что если LLM-провайдер недоступен? | Multi-LLM router с fallback (YandexGPT → GigaChat → Llama → FakeLLM). Никогда не падаем. |
| Как защищены данные клиента? | Multi-tenant изоляция по customer_id, JWT + RBAC. БД в РФ (Yandex Cloud / on-prem). 152-ФЗ маскинг PII. |
| Сколько LLM-запросов на лот? | 3-5 запросов на лот: Planner, Verifier, Reporter (Sourcer/Negotiator используют LLM опционально). При 50 000 лотов/год это ~200 000 запросов. |
| Что в Excel? | Top-3 поставщиков (наименование, ИНН, цена, срок, score, рекомендация), сводка по лоту, история торгов. |
| Что делать с антимонопольными нарушениями? | Verifier проверяет аффилированных лиц (один ИНН → разные «компании») и подаёт `escalation_reason="suspected_collusion"` → менеджеру. |
| Как обучается на исторических данных? | Pre-bid: historical_purchases.csv → Qdrant с эмбеддингами цен. Sourcer ищет «похожие лоты» через vector search. После закрытия лота — добавляем в historical. |
