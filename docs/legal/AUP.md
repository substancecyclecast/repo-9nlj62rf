# Acceptable Use Policy (AUP) — SnabAgent

**Версия 1.0 от 01.01.2026**

## 1. Область применения

Настоящая политика применяется ко всем пользователям ПО SnabAgent и определяет допустимые способы использования сервиса.

## 2. Допустимое использование

SnabAgent предназначен **только** для:
- автоматизации B2B-закупочной деятельности юридического лица;
- работы с легально полученными заявками и КП;
- генерации отчётов и аналитики для внутренних нужд;
- интеграции с внутренними системами Лицензиата (КИС, 1С УХ).

## 3. Запрещённые действия

Лицензиату запрещается:

### 3.1. Технические нарушения

- Попытки обхода ограничений безопасности, RBAC, лимитов тарифа.
- Реверс-инжиниринг, декомпиляция, модификация исходного кода ПО.
- Создание производных продуктов на основе SnabAgent.
- Перепродажа доступа к ПО третьим лицам без согласия Лицензиара.
- Использование автоматизации (бот, скрипт) для обхода лимитов API.

### 3.2. Нарушения безопасности

- Передача учётных данных, JWT-токенов, API-ключей третьим лицам.
- Попытки доступа к данным других customer-tenant.
- Использование ПО для DDoS-атак на сторонние ресурсы.
- Загрузка вредоносного кода (вирусы, шифровальщики) через файлы вложений.

### 3.3. Юридические нарушения

- Использование ПО для деятельности, нарушающей законодательство РФ.
- Обработка персональных данных без правовых оснований по 152-ФЗ.
- Использование ПО для отмывания денег, финансирования терроризма.
- Антимонопольные нарушения (картельные сговоры, дружественные КП).
- Загрузка контента, нарушающего права интеллектуальной собственности.

### 3.4. Нарушения политики использования LLM

- Загрузка данных, направленных на «джейлбрейк» LLM (попытки извлечь системный промт, обойти этические ограничения).
- Использование ПО для генерации:
  - оскорбительного или дискриминирующего контента;
  - дезинформации, фейковых КП;
  - содержания, унижающего честь и достоинство.

### 3.5. Чувствительные данные

- **Запрещена обработка:**
  - паспортных данных, СНИЛС физических лиц;
  - медицинских данных, биометрии;
  - сведений, составляющих государственную тайну;
  - информации, отнесённой к 1-й категории персональных данных по 152-ФЗ.

## 4. Лимиты использования

### 4.1. Лимиты тарифа

Лицензиат обязан соблюдать лимиты выбранного тарифа:
- максимальное количество лотов в месяц;
- максимальное количество пользователей;
- максимальное количество customer-tenant.

При превышении лимитов сервис автоматически:
- предупреждает через email/Telegram;
- блокирует приём новых лотов до конца месяца;
- предлагает upgrade на следующий тариф.

### 4.2. Rate-limiting

API имеет ограничение **100 запросов в минуту на пользователя**. При превышении возвращается HTTP 429.

### 4.3. Размер файлов

Максимальный размер вложения — **10 МБ**. Поддерживаемые форматы: PDF, DOCX, XLSX, TXT.

## 5. Санкции за нарушение

При нарушении настоящей политики Лицензиар вправе:

### 5.1. Уровень 1 (предупреждение)

- Уведомление по email и в UI.
- Срок устранения нарушения — 7 дней.

### 5.2. Уровень 2 (временная блокировка)

- Приостановка доступа на 24-72 часа.
- Письменное уведомление о причинах.

### 5.3. Уровень 3 (расторжение)

- Расторжение договора без возврата средств.
- При наличии ущерба — взыскание в судебном порядке.
- При уголовных нарушениях — обращение в правоохранительные органы.

## 6. Сообщение о нарушениях

Если вы обнаружили нарушение этой политики со стороны других пользователей или третьих лиц, сообщите:
- email: abuse@snabagent.example
- безопасность: security@snabagent.example

## 7. Изменения

Лицензиар вправе изменять настоящую политику с уведомлением Лицензиата за 30 дней.
