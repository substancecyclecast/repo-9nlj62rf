## Конкурентные преимущества SnabAgent

### 1. **Скорость цикла**
- Полный цикл за 30-60 секунд (реальные LLM) vs дни/недели у конкурентов.
- Возможно благодаря LangGraph + параллельным агентам.

### 2. **Российская юрисдикция и LLM**
- Единственное полнофункциональное решение с YandexGPT/GigaChat как primary LLM.
- Соответствие 152-ФЗ из коробки, без доп. модулей.
- Хранение данных и LLM-запросов внутри РФ (Yandex Cloud / on-prem).

### 3. **Полная автоматизация**
- Конкуренты автоматизируют 20-40% цикла (RFP-распыл, классификация).
- SnabAgent — 90% (только финальное одобрение остаётся за человеком).

### 4. **Антимонопольный модуль**
- Никто из конкурентов не делает «антисговор» автоматически.
- Verifier проверяет аффилированных лиц, дубли ИНН, дружественные ответы.

### 5. **Цена**
- 5-10x дешевле SAP Ariba для холдинга 50 000 лотов/год.
- ROI 2-3 месяца на одном крупном клиенте.

## Где SnabAgent ещё не дотягивает (честно)

- **Глубокая EDI/SOAP интеграция с 1С УХ** — Bidzaar и SAP Ariba имеют готовые коннекторы.
  - Решение: на pilot-фазе делаем выгрузку договоров через Excel/REST API, далее коннектор через 4-8 недель.
- **Маркетплейс поставщиков** — Bidzaar предоставляет каталог из 50 000+ поставщиков из коробки.
  - Решение: интеграция со СПАРК-Интерфакс + Контур.Фокус (Q2 2026).
- **Мобильное приложение** — Bidzaar/SAP Ariba имеют iOS/Android.
  - Решение: PWA через Streamlit (Q1 2026), нативное приложение (Q3 2026).

## Стратегия выхода

1. **Pilot (1 квартал):** 3 пилотных проекта в холдингах СИБУР / Северсталь / Газпром нефть.
2. **GA (2 квартал):** общедоступный SaaS, тарифы Pilot/Pro/Enterprise.
3. **Partnership (3 квартал):** соглашения с системными интеграторами (Крок, ИТ-Решения, Softline).
4. **Маркетплейс (4 квартал):** портал для поставщиков, self-service onboarding.
