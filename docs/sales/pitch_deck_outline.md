## Слайд 2 — Проблема

Российский крупный холдинг: 50 000+ закупочных лотов / год, 5–15 дней цикл на лот.

**4 «болевых» точки:**

| # | Боль | Стоимость |
|---|------|------|
| 1 | Сотрудники тратят 60% времени на копи-пейст из PDF/Excel в КИС | 350 ₽/час × 4 часа × 50 000 лотов = **70 млн ₽/год** |
| 2 | Реестр поставщиков обновляется вручную, реестр в Excel | Риск 1 «закрытого» поставщика = до 50 млн ₽ убытка |
| 3 | Сравнение КП без анти-сговора и без проверки ГОСТ | 5–10% переплат вследствие «дружественных» КП |
| 4 | Согласование KP через переписку | 3–10 дней блокирующего ожидания |

> **Итого выгода: ~250–500 млн ₽/год** для холдинга с оборотом 100 млрд ₽.

## Слайд 3 — Решение

**SnabAgent — система из 6 LLM-агентов, замыкающая полный цикл:**

```
заявка от заказчика
     ↓
[Planner]    — извлекает структурированные позиции из «грязного» текста
[Sourcer]    — подбирает поставщиков из НСИ + СПАРК + историии
[Communicator] — рассылает RFQ по email/телефону
[Negotiator] — собирает ответы, торгуется
[Verifier]   — валидирует ИНН, ГОСТ, лицензии, антимонопольно
[Reporter]   — Top-3 + Excel + Telegram-эскалация
     ↓
закупщик: одобрить / отклонить → договор
```

**Главное:** работает **без участия человека**, кроме финальной одобрения подходящего предложения.

## Слайд 5 — Архитектура

```
                    ┌─────────────┐
заказчик ──HTTP──→ │  FastAPI    │ ←→ Streamlit (UI)
                   │  /lots/*    │
                   └──┬─────┬────┘
                      │     │
                  Redis    PostgreSQL
                      │     │
                      ▼     ▼
                  ┌──────────────┐
                  │  LangGraph   │ Planner→Sourcer→Communicator
                  │  pipeline    │  →Negotiator→Verifier→Reporter
                  └──────┬───────┘
                         │
              ┌──────────┼──────────┬─────────────┐
              ▼          ▼          ▼             ▼
          Qdrant     YandexGPT  GigaChat   SMTP/IMAP
          (НСИ)     (primary)  (fallback)  (Mailcow)
```

- **Multi-LLM fallback:** YandexGPT → GigaChat → Llama-3 → FakeLLM (демо)
- **Хранилище:** PostgreSQL (lots, audits) + Qdrant (semantic search НСИ)
- **Безопасность:** PII-маскинг в audit log, JWT-логин, RBAC (admin/buyer/viewer)
- **Наблюдаемость:** /metrics (Prometheus), Grafana dashboard, /health
- **Развёртывание:** Yandex Cloud / on-prem k8s, Docker-compose в 1 команду
