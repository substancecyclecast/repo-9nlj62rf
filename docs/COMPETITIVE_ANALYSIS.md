## 4. Competitive Moats

### Moat 1: Multi-chain + Stellar Integration
- Only solution spanning EVM + Solana + Stellar
- SEP-31 anchor network = 45+ country coverage
- Path payments = atomic FX (no competitor has this)

### Moat 2: On-chain Policy (Soroban)
- Spending limits enforced by smart contracts, not just code
- Compliance allowlists on-chain = auditable
- Time-locked withdrawals = safety for large orgs

### Moat 3: Double-Entry Ledger
- Every transaction creates balanced journal entries
- Trial balance always reconciles
- This IS the system of record → massive switching cost

### Moat 4: AI Agent with Audit Trail
- Every decision auditable (AgentRun → AgentRunStep)
- Policy-bounded: never exceeds limits
- Deterministic fallback = reliable even without LLM

### Moat 5: Data Network Effects
- Payee graph grows over time (shared contractor database)
- Routing intelligence improves with volume
- Cross-org benchmarks (avg. payment cost, yield deployed)
